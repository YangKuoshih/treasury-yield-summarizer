# Treasury Yield Summarizer

A Treasury yield-curve dashboard with AI-generated market commentary — interactive
yield curve charts, rate tables, and per-tenor summaries.

## Features

- **Yield curve chart** — full curve visualisation across tenors
- **Market rates table** — current rates with movement
- **AI summary panel** — generated commentary on curve shape and movement
- **Per-tenor summaries** — focused analysis for a selected point on the curve
- **Light / dark themes**

## Stack

Next.js · React · TypeScript · Tailwind CSS · shadcn/ui

## Getting started

```bash
npm install
npm run dev
```
